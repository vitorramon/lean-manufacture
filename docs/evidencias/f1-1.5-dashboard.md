## 2. Ponta a ponta (gateway + aas-sync + Streamlit + emulador roteiro)

Base no ar (broker `localhost:1883`, AAS `localhost:8091`). Da raiz do repositório:

```bash
uv run --project pipeline/device_gateway python -m device_gateway
uv run --project pipeline/aas_sync python -m aas_sync                       # DB_PATH=dados/dados.db
uv run --project app streamlit run app/Home.py --server.port 8501 --server.headless true
curl -s -w " HTTP %{http_code}\n" http://localhost:8501/_stcore/health     # → ok HTTP 200
uv run --project hardware/emulador emulador --fonte roteiro --dispositivo esp32-bat01 --velocidade 2
```
