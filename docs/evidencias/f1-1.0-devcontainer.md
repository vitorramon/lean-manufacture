## 4. Planta sem janela, 30 s, dentro do contêiner

### 1ª tentativa: 0 mensagens

```
$ docker run --rm --network=host -v "$PWD":/workspace lean-m3-dev:1.0 godot --headless --path base/godot -- --vf-quit-after=30
WARNING: MQTT: broker ws://localhost:9001 unavailable (connection closed); retrying in the background
WARNING: Backplane: communication module of PLC01 not reachable at tcp://localhost:4841 (retrying)
UNS: session S-20261115T231626Z-5ba9 published 0 messages {...} in 29.5 s simulation / 29.4 s wall time
```

Diagnóstico: no contêiner, `localhost` resolve primeiro para `::1`, e na rede host do Docker Desktop o `::1` recusa
conexão (`::1 9001 falhou [Errno 111] Connection refused`; `127.0.0.1 9001 conectou`). O log do broker não registrou
nenhuma conexão na porta 9001 durante a execução. Com `--vf-uns=ws://127.0.0.1:9001 --vf-backplane=tcp://127.0.0.1:4841
--vf-aas-url=http://127.0.0.1:8091` a planta conectou (1277 mensagens em 7,5 s). Correção genérica, sem tocar na base:
`/etc/gai.conf` com `precedence ::ffff:0:0/96 100` na imagem (testado primeiro montando o arquivo: 1261 mensagens em
7,5 s, os dois clientes MQTT conectados).
