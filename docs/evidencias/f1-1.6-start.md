### Teste de falha 1: SIGKILL no emulador (socket fechado sem DISCONNECT)

`kill -9` no grupo da fonte às 00:06:37.995Z. Sonda OPC UA (`Bateria_01.Online`, 1 Hz):

```
2026-11-16T00:06:37.377+00:00 Online True SourceTimestamp 2026-11-16T00:05:33.671+00:00
2026-11-16T00:06:40.383+00:00 Online False SourceTimestamp 2026-11-16T00:06:37.999+00:00
```

O `Online` ficou falso 4 ms depois do kill: o broker publica o Last Will assim que percebe o socket fechado. A
sessão foi fechada em `sessoes` (`fim` = `00:06:37.999356+00:00`). Andon pelo `nucleo` (`dados.py`, `regras.py`):

```
2026-11-16T00:07:29.430+00:00 cinza | dispositivo offline (status offline ou Last Will) | sessao fechada
```

Esta leitura do Andon foi feita 51 s depois do kill. A primeira sonda falhou por erro meu: rodou de dentro de
`app/` e procurou o banco em `app/dados/dados.db`. O tempo até o cinza está medido no teste 2.

O monitor do `start.py` acusou a falha no ciclo seguinte:

