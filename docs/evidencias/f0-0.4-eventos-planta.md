Campos de `part_released` (AC01): `event, device, session, seq, ts, serial, cap_variant, leak_rate, stroke_time, lots`. Exemplo: `cap_variant` 0/0/2, `leak_rate` 0,359/0,443/0,757, `stroke_time` 0,322/0,338/0,324, `lots` = 9 pares `Componente=lote` separados por `;` (Barrel, EndCapFront, EndCapRear, PistonRod, Piston, SealKit, ScrewM5x16, CushioningScrew, ProtectiveCap).

Campos de `part_inspected` / `part_sorted`: **não observados**. Pela documentação da base (`base/docs/interfaces/uns.md`, §Events), `part_sorted` traz `event, device=PLC01, session, seq, ts, serial, container, slot`, e "One serial goes released → inspected → sorted". Os dois eventos saem do edge (eventos OPC UA do PLC) com o contador `seq` do próprio PLC. Isso é documentação e não foi observado aqui.

Rastreio (ADR-0008): o `serial` tem o formato `PC3280-2026-NNNNNN` e é sequencial por sessão. A igualdade do serial nos três eventos **não foi confirmada nesta rodada**: só houve `part_released`.
QR / Digital Link: pelo código (`godot/products/cylinder/cylinder_workpiece.gd`, `cylinder_label.gd`, ADR-0023 da base), a plaqueta da peça leva o QR do GS1 Digital Link `https://virtual-factory.example/01/04099999032808/21/<serial>` (AI 01 = GTIN 04099999032808, AI 21 = serial). Isso foi lido no código e no teste `test_cylinder_label.gd`, sem render observado.

## Bloqueio e próximo passo

- Causa: Git LFS ausente (já registrado na 0.2). Há um `git-lfs` 3.6.1 em `scratchpad/gitlfs/` (deixado por outra tarefa da sessão; sha256 `2138d2e4…8d76` confere com o `sha256sums.asc` oficial). A tentativa de usá-lo foi **negada pelo controle de permissões**: `PATH=<scratchpad>/gitlfs/git-lfs-3.6.1:$PATH git -C base lfs pull --include="godot/**"`.
- O usuário precisa fazer: `sudo apt install git-lfs && git lfs install` (ou autorizar o binário de usuário) e `git -C "Documentation/Atividade/MOD 3/base" lfs pull`. Depois, repetir os passos 1–3 desta tarefa.
- Limpeza: a importação alterou 48 arquivos `*.import` do submódulo (efeito dos ponteiros). Foram revertidos com `git -C base checkout -- godot`, e `git status` do submódulo ficou limpo. A pasta `godot/.godot/` (cache, ignorada pelo git) ficou.
